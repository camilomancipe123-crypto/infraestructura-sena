Tecnología con propósito

La importancia de las TIC

Las tecnologías de la información y las comunicaciones facilitan el acceso a la información, la colaboración y la conexión entre personas y organizaciones.

Comunicación

Conectan personas y permiten compartir información.

Productividad

Apoyan la organización de datos y actividades cotidianas.

Aprendizaje

Abren oportunidades para consultar recursos y desarrollar habilidades.

Conceptos esenciales

Glosario tecnológico

Consulta definiciones sencillas de términos frecuentes.

BIOS/UEFI
Firmware que inicia el equipo y prepara el hardware para cargar el sistema operativo.
Cableado estructurado
Organización del cableado y puntos de conexión de una infraestructura.
CPU
Procesador que ejecuta instrucciones y coordina operaciones del equipo.
Dirección IP
Identificador utilizado para comunicar un dispositivo en una red.
HDD
Disco duro que almacena información en platos magnéticos.
Mantenimiento preventivo
Revisiones y cuidados periódicos destinados a reducir fallas.
RAM
Memoria temporal que almacena datos y programas mientras se usan.
Router
Dispositivo que dirige el tráfico entre redes.
Sistema operativo
Software que administra recursos y permite ejecutar aplicaciones.
SSD
Unidad de almacenamiento que utiliza memoria de estado sólido.
Switch
Dispositivo que conecta equipos dentro de una red local.
